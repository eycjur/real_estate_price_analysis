# 不動産売却価格 回帰分析

国土交通省の取引価格データで、日本の主要大都市(東京23区+政令指定都市)の中古マンション・中古戸建の価格をヘドニック回帰し、
「築年数が1年増えると何%下がるか」を回帰方程式・誤差・断面グラフで確認する Web アプリです。
社人研の将来推計人口を使い、区ごとの人口推移を織り込んだ将来価格も試算します。
住宅・土地統計調査の家賃と組み合わせ、ワンルーム投資などの想定利回り(表面・実質・ローン返済後)を、築年数や購入した年の断面で出せます(空室率・修繕積立金・ローン金利などの前提は画面で変更可能)。
日銀・財務省の金利と国交省の不動産価格指数も並べて見られます。
ほかに、首都圏の成約・新規登録・在庫件数から成約率・在庫月数を種類・地域・価格帯の断面で見る「市況」と、変動/固定・住宅/投資用ローンの金利推移、商品の金利比較、返済額の計算をまとめた「ローン・金利」、全国の市区町村の人口の増減を地図で見て、主要都市の推移を年齢層・男女別に比べる「人口」のページ、
地価(1955年〜)・家賃(1970年〜)・物価と政策金利・ローンの目安になる金利(公定歩合は1882年〜)の超長期の推移を都市別に比べる「長期推移」のページがあります。

東日本レインズ・市街地価格指数を除き、いずれも公共データ利用規約(PDL1.0)または同等の条件(出典と加工した旨の記載で、公開・商用を含め利用可)です。
東日本レインズの統計は出典の明記で引用・転載できますが、「継続的な転載等を行う場合は事前に問い合わせ」、リンクはトップページのみ、統計を主な内容とする営利目的の資料は不可、という条件があります([著作権と引用・転載等について](https://www.reins.or.jp/copyright/copyright.pdf))。画面のフッターに出典と「加工して作成」の表記を入れています。市街地価格指数は日本不動産研究所の著作物で、同所はデータでの配布をしていないため、BIS が公表している系列(出典の明記で利用可)を使い、出典を画面に記載しています。国土地理院タイルは出典の明示とリンクのみで利用できます。

元データ(`data/`)はリポジトリに含めず、各自で取得します。ブラウザ用に加工したデータ(`docs/data/`、約7MB)はサイトの一部としてリポジトリに含めています(加工データの複製・公衆送信は各規約で認められています)。利用時は各サイトの利用規約に従い、出典を明記してください。

## 構成

サーバーは不要で、`docs/` をそのまま静的サイトとして配信します(GitHub Pages 対応)。回帰などの計算はすべてブラウザ内の JS (Web Worker) で行います。

| 場所 | 役割 |
|---|---|
| `docs/index.html` `docs/js/` | 画面と計算。`model.js`(回帰)、`service.js`(断面・将来予測・利回り・相場)、`data.js`(データ読み込み)、`worker.js` |
| `docs/data/` | ブラウザ用データ(約12MB)。都市×種別ごとの列指向バイナリ(gzip)と `meta.json`、金利・価格指数の `rates.json`、市況の `market.json`、ローンの `loan.json`、人口の `population.json` と地図の境界 `boundaries.json`、長期推移の `long.json`。`reap.export` が生成 |
| `data/reference/` | 公式ページ・PDF を見て手で入力した参照データ(商品の金利、金利タイプ別の利用割合)。リポジトリに含める |
| `src/reap/etl.py` | `data/raw/` の公的データを `data/processed/*.parquet` に整形 |
| `src/reap/export.py` | parquet から `docs/data/` を書き出す。人口弾力性(全都市プール推定)だけはここで事前計算 |
| `src/reap/model.py` | 回帰の参照実装(Python)。JS 版と結果が一致することをテストで確認 |

## データの取得

いずれも各サイトからブラウザでダウンロードして、`data/raw/` に置きます(`data/` は Git 管理外)。

### 1. 取引価格 (国土交通省 不動産情報ライブラリ)

<https://www.reinfolib.mlit.go.jp/realEstatePrices/> を開き、次の条件で「ダウンロード」を押すと zip が保存されます。

| 項目 | 指定 |
|---|---|
| 都道府県 | 北海道、宮城県、埼玉県、千葉県、東京都、神奈川県、愛知県、京都府、大阪府、兵庫県、広島県、福岡県 (1件ずつ) |
| 市区町村 | 指定しない(都道府県全域) |
| 価格情報区分 | 「不動産取引価格情報」「成約価格情報」の両方にチェック |
| 種類 | 「中古マンション等」と「宅地(土地と建物)」を別々に |
| 取引時期 | 2010年第1四半期 〜 最新 |

- 12都道府県 × 2種類 = 24ファイルです。保存される zip はどの種類でも同じ名前(例: `Tokyo_20101_20261.zip`)になるので、`13_used.zip`(中古マンション等)、`13_building.zip`(土地と建物)のように、都道府県コードと種類が分かる名前に変えて `data/raw/` に置いてください(名前自体は自由です。`data/raw/*.zip` をすべて読みます)。
- 大きな都道府県は、押した直後に「ファイルを作成中」の案内が出ることがあります。1〜2分待ってから同じ条件でもう一度押すと保存されます。
- 中身の CSV は Shift_JIS で、`reap.etl` がそのまま読みます(展開は不要)。

### 2. 人口 (国立社会保障・人口問題研究所「日本の地域別将来推計人口」)

次の3つの推計それぞれについて、対象12都道府県の Excel を保存します(市区町村別・男女5歳階級別の結果)。

| 推計 | ページ | 保存先 |
|---|---|---|
| 令和5年推計 (2020年実績+2025〜2050年推計) | <https://www.ipss.go.jp/pp-shicyoson/j/shicyoson23/t-page.asp> → 結果表 → 都道府県別 (`01.xlsx` など) | `data/raw/ipss2023/` |
| 平成30年推計 (2015年実績) | <https://www.ipss.go.jp/pp-shicyoson/j/shicyoson18/t-page.asp> (`01.xls` など) | `data/raw/ipss2018/` |
| 平成25年推計 (2010年実績) | <https://www.ipss.go.jp/pp-shicyoson/j/shicyoson13/t-page.asp> (`01.xls` など。千葉県のみ `12.xlsx`) | `data/raw/ipss2013/` |

ファイル名は都道府県コード(`01` `04` `11` `12` `13` `14` `23` `26` `27` `28` `34` `40`)のままにします。

### 3. 家賃 (総務省統計局「令和5年住宅・土地統計調査」)

e-Stat の「住宅及び世帯に関する基本集計 → 全国・都道府県・市区町村」から次の2表を Excel で保存し、`data/raw/rent/` に置きます。

| 表 | 内容 | 保存名 |
|---|---|---|
| 第130表 | 住宅の建て方、延べ面積別 民営借家(専用住宅)の1か月当たり家賃 (市区別) | `t130.xlsx` |
| 第107-2表 | 建築の時期別 借家の1畳当たり家賃 (全国・都道府県・21大都市) | `t107_2.xlsx` |

統計表の一覧: <https://www.e-stat.go.jp/stat-search/files?toukei=00200522&tstat=000001207800>

### 4. 地区の位置 (国土交通省「位置参照情報」)

<https://nlftp.mlit.go.jp/isj/> から「大字・町丁目レベル」の最新版を、対象12都道府県ぶん zip のまま `data/raw/isj/` に置きます(ファイル名は `01.zip` のように都道府県コード)。

### 5. 金利と不動産価格指数

`scripts/download_stats.sh` の末尾が `data/raw/rates/` に取得します(人口・家賃・位置参照情報も同じスクリプトで取得できます)。手動で置く場合は次の通り。

| ファイル | 内容 |
|---|---|
| `boj_ir01.csv` `boj_fm02.csv` `boj_ir04.csv` | 日銀「主要時系列統計データ表」の CSV(`https://www.stat-search.boj.or.jp/ssi/mtshtml/csv/<コード>_m_1.csv`)。ir01=基準貸付利率、fm02=無担保コールレート、ir04=貸出約定平均金利 |
| `boj_prime.html` | 日銀「長・短期プライムレート(主要行)の推移」のページをそのまま保存 |
| `jgbcm_all.csv` | 財務省「国債金利情報」の全期間 CSV |
| `mlit_rpi.xlsx` | 国交省「不動産価格指数(住宅)」の Excel。公表ページの「不動産価格指数(住宅) Excel」のリンク先で、公表のたびに URL が変わるためスクリプト内の URL が切れたら差し替える |

### 6. 市況とローン

`scripts/download_stats.sh` の末尾が `data/raw/reins/` `data/raw/market/` `data/raw/loan/` に取得します。

| ファイル | 内容 |
|---|---|
| `reins/MW_YYYYMMdata.pdf` | 東日本レインズ「月例速報 Market Watch」の詳細データ。各号に直近13か月(価格帯別は5四半期)が載るので、2015年以降の8月号と最新号を置く(重なる月は新しい号の値を使う。欠けがあれば `reap.etl` が止まる)。`www.reins.or.jp` は中間証明書を送らないため、curl では発行元の中間証明書を足して検証する(スクリプト参照) |
| `market/mlit_sales_index.xlsx` | 国交省「既存住宅販売量指数」の Excel |
| `market/starts_pref.xls` | 建築着工統計の「【住宅】都道府県別着工戸数」(e-Stat の長期時系列。ファイル ID は毎月変わる) |
| `loan/jhf_chintai_rates.pdf` | 住宅金融支援機構「賃貸住宅融資 参考金利の推移表」 |
| `loan/boj_la01.csv` | 日銀 API の貸出先別貸出金(住宅資金・個人による貸家業の新規貸出) |

### 7. 人口タブ

`scripts/download_stats.sh` の末尾が、社人研の推計を全47都道府県ぶん(`ipss2023/` `ipss2018/`)と、国土数値情報「行政区域」の都道府県別 zip(`n03/N03-20240101_<都道府県コード>_GML.zip`、zip のまま)を取得します。境界は表示用に約400mの精度に間引いて `docs/data/boundaries.json`(約1.3MB)に、人口は男女・5歳階級別に `docs/data/population.json`(約3MB)に書き出します。2025年は令和7年国勢調査の実績(`census2025/age5.xlsx`)で推計を置き換えます。福島県の浜通り13市町村は推計が「浜通り地域」としてまとめられているため(2025年の実績も同じ単位に合計)、地図ではその境界をまとめて塗ります(浜松市も2024年の区の再編で境界と推計の区が違うため市全体で塗ります)。

`data/reference/` の2つの CSV は自動では取得しません。金利が変わったら公式ページで確認して書き換え、`reap.export` を実行し直してください。

| ファイル | 内容 |
|---|---|
| `loan_products.csv` | 代表的な商品の金利(公式ページで表示を確認した値のみ。基準日・URL・条件つき) |
| `jhf_rate_type_share.csv` | 「住宅ローン利用者の実態調査」各回の概要 PDF にある金利タイプ別の利用割合 |

### 8. 長期推移タブ

`scripts/download_stats.sh` の末尾が `data/raw/long/` に取得します。

| ファイル | 内容 |
|---|---|
| `L01-26_<都道府県コード>_GML.zip` | 国土数値情報「地価公示」(zip のまま)。最新年の地点ごとに1983年からの価格の履歴があり、住宅地の連鎖指数を都市ごとに作る。毎年4月頃に新しい年版が出たら、スクリプトの `KOJI` を更新する |
| `cpi_nation.csv` | 消費者物価指数 長期時系列の全国「持家の帰属家賃を除く総合指数(1947年〜最新年)」(CSV) |
| `cpi_<市区町村コード>.xlsx` | 同じく都市別の中分類指数(1970年1月〜最新月、Excel。年平均の「持家の帰属家賃を除く家賃」を使う)。東京23区は `13100` |
| `bis_dpp_jp.csv` | BIS の日本の住宅地価格指数(日本不動産研究所「市街地価格指数」、半年ごと。各年3月末の値を使う) |
| `boj_ir01_api.csv` `boj_fm02_api.csv` | 日銀 API の基準割引率および基準貸付利率(1882年〜)、有担保コールレート翌日物(1960年〜) |
| `boj_primeold.html` `boj_primeold2.html` | 日銀「長・短期プライムレート」の過去の表(1966〜1988年、1989〜2000年)。2001年以降は `rates/boj_prime.html` |

e-Stat のファイル ID はスクリプトに直接書いています。取得できなくなったら、[消費者物価指数の長期時系列データ](https://www.e-stat.go.jp/stat-search/files?toukei=00200573&tstat=000001150147)の一覧で該当の表の ID を確認して差し替えてください。

### 一棟もの(都市ごとの分析の「種別」で選択)

種別「一棟マンション(RC・SRC)」「一棟アパート(木造・鉄骨)」は、取引価格情報の「宅地(土地と建物)」のうち用途が「共同住宅」だけの取引です(店舗・事務所との併用や混構造は除く)。成約価格情報には一棟ものがないため、取引価格情報(アンケート)だけになります。戸建と同じ変数に加えて「容積率の消化率」(延床 ÷ (土地面積 × 容積率)。100%超は既存不適格の可能性)を入れ、価格情報の種類は使いません。戸数はデータにありません。
構造で分けているのは、築年数による価格の下がり方が RC と木造系で大きく違うためです。木造・軽量鉄骨・鉄骨の間では下がり方の差が数ポイントと小さく(構造ごとに曲線を分けても残差の標準偏差は 0.3451→0.3445)、分けると多くの都市で件数が足りなくなるため、一棟アパートにまとめて構造を変数として入れています。件数が200件未満の都市(堺市・千葉市などの一棟マンション)は推定できません。

## モデル

```
ln(価格) = 築年数(1年刻みのダミー) + ln(面積) [+ ln(土地面積): 戸建] + 駅徒歩分
          + 構造 + 改装 + 間取り + 用途地域 + 容積率 + 今後の利用目的 + 価格情報の種類 + 取引四半期
          [+ 土地の形状 + 前面道路(方位・種類・幅員) + 間口 + 地域: 戸建]
          + 区固定効果 + 取引年固定効果 + 地区(町名)効果(L2) + ε
```

- 築年数は1年刻みのカテゴリ変数(基準 築10年)。曲線の形を仮定しないので、新築直後の急落なども拾えます。データにない築年数(60年超の将来予測など)は最も近い年の値で代用します。
- 連続変数は「基準の物件」(マンション: 築10年・20㎡・駅徒歩10分・間取り1K / 戸建: 築10年・建物100㎡・土地100㎡・駅徒歩10分)からの差で入れているので、exp(切片) がそのまま基準の物件の価格です。カテゴリ項目の基準は最頻の水準、区は取引最多の区、取引年は最新年。
- 地区効果は L2 罰則の性質上、各区の中で合計がちょうど0になります。区効果が「区の水準」、地区効果が「区平均からのズレ」を分担するので、二重計上にはなりません。
- 説明変数と地区効果は固定で、常にすべて投入します。画面では項目ごとに「Xなら価格が何%変わるか」のカードで表示し、行をクリックするとその条件を基準に切り替えられます(予測と実績、築年数・取引年のグラフつき)。成約価格情報に無い項目は「不明」を独立の区分にして標本を落とさず、完全に重複する列は自動で除外します。
- 通常の変数は罰則なし。件数(数万〜数十万)に対して変数は数十個なので過学習は起きず、係数・標準誤差をそのまま解釈できます。
  L2 罰則(λ=10)は水準が数千ある地区名だけに掛けます(混合効果モデルのランダム効果に相当)。区人口は将来予測用の全都市プール推定でのみ使います。
  東京23区の中古マンションでは、検証用2割での残差標準偏差が 0.237(基本変数)→ 0.233(全変数)→ 0.208(+地区L2)。λ は1〜30でほぼ同じです。
- 最小二乗法。標準誤差は HC1(全都市プール時は区クラスタ頑健)。参照実装は `tests/test_model.py` で statsmodels と、JS 版は `tests/test_js_matches_python.py` で参照実装と一致を確認。
- 画面の「典型的な誤差」は exp(残差の標準偏差) − 1。
- 将来予測 = 現在の推定価格 × 経年減価 × 人口効果。人口効果の弾力性は全都市プール・区固定効果+都市×年固定効果で推定。
  金利や景気など市場全体のトレンドは横ばいと仮定しており、弾力性も因果効果とは限りません。
- 利回り: 想定家賃 = 区×面積区分の平均家賃 × 築年補正。統計の家賃は入居中世帯の平均で新規募集家賃より低めに出やすいため、画面で家賃を直接指定できます。
  表面 = 年間家賃 ÷ 価格、実質 = NOI(空室・管理委託・管理費・固定資産税を引いた後) ÷ 総投資額(価格×(1+諸費用))、返済後 = (NOI − 年間ローン返済額) ÷ 総投資額。
  ローンは元利均等・借入額=推定価格で、金利は選んだ公表統計の購入年の年平均+上乗せ幅。実際の住宅ローン金利(優遇後)の統計はないため、用途(投資用 変動=短期プライムレート+1.5%、自宅用 変動=短プラ−1.0%、自宅用 固定=10年国債+0.8%)の目安を初期値にし、系列と上乗せ幅を手で変えられる形にしています。
  断面は「築年数」(選択中の取引年で固定)と「購入した年」(築年数・家賃を固定し、価格は取引年効果、金利はその年の値)。税・一時的な修繕費・売却損益は含みません。
- 金利と価格指数: 日銀・財務省の金利(月次)と国交省の不動産価格指数(住宅、季節調整済み、2010年=100)を、回帰の取引年効果(物件条件を固定した各年の推定価格を2010年=100にしたもの)と重ねます。

回帰方程式の欄には、予測と実績・築年数・取引年のグラフに加えて、立地マップ(区効果+地区効果を地区の代表点に色で描いたもの)と区効果の棒グラフを並べています。

画面はページ上部で「都市ごとの分析(回帰)」と「全国の比較(相場)」を切り替えます。全国の比較は回帰を使わず、面積・築年数・駅徒歩・取引年の条件に合う実取引の中央値と四分位を都市別・区別に集計します。取引される物件の築年数は都市で大きく違うので、実取引の中央値と統計の家賃を割った利回りは出さず、条件の中央の「標準物件」(同じ築年数・面積・駅距離)に揃えて、回帰の推定価格と同じ築年数の家賃から表面利回りを比較します。㎡単価の推移は全地域の線を重ね、選んだ1地域だけ強調します(推移は取引年の条件を外した全期間)。

前処理の詳細は画面の「データと方法」タブを参照。

市況: 成約率 = 成約件数 ÷ 新規登録件数、在庫月数 = 月末の在庫件数 ÷ 月平均の成約件数。季節変動が大きいため、どちらも12か月の合計・平均で計算します。価格帯で絞り込むと、その価格帯の四半期の件数(直近4四半期の合計で比率を計算)になります。価格帯別は首都圏と都県の単位でのみ公表され、最上位の区分はマンションが「1億円超」、戸建・土地が「2億円超」です。2025年1月以降は成約登録の適正化(システム改修)で成約件数が増えた可能性があると機構が注記しています。
長期推移: 都市別の地価は地価公示の住宅地で、毎年、前年から継続して調査された地点(標準地番号の変更を含む)の価格の変化率を対数平均してつないだ連鎖指数(最新年=100)。元データは最新年に残る地点の履歴なので、古い年ほど地点が少なくなります(東京23区で1984年は約90地点)。家賃は消費者物価指数の都市別「持家の帰属家賃を除く家賃」(建物の経年による家賃の低下を十分に補正しないため、上昇が小さく出やすい)。基準年=100 にそろえ、実質は全国の物価で割ります。「地価÷家賃」は基準年からの変化で、利回りの水準ではありません。基準年に値のない価格の系列(マンションの不動産価格指数 2008年〜、市街地価格指数の東京区部 1985年〜)は、最初の年を地価公示の値に合わせて描きます。金利は民間の住宅ローン金利の長期の数表がないため、政策金利(公定歩合・コールレート)と、ローンの目安になる長短プライムレート・10年国債・貸出約定平均金利を並べ、変動金利の店頭金利は短プラ+1%を目安にしています。
ローン: 民間の住宅ローン金利やフラット35の過去の値は数表で公表されていないため、変動は短期プライムレート(大手行の店頭金利 = 短プラ+1% の慣行)、固定は10年国債・長期プライムレート、投資用は機構の賃貸住宅融資の金利で推移を描き、現在の商品の金利を重ねています。ローンのページの「返済額の計算」は借入額・金利・期間から月々の返済額・利息・総返済額を出します(元利均等/元金均等)。「変動と固定の比較」は元利均等で、変動は毎年その時点の残高・残期間で返済額を計算し直します(5年ルール・125%ルールは考えない)。
